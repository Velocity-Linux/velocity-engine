# Contributing

Thank you for your interest in contributing to Velocity Engine!

## Code of Conduct

Be respectful and constructive. We are committed to providing a welcoming and inclusive experience.

## Development Setup

```bash
git clone https://github.com/velocity-os/velocity-engine.git
cd velocity-engine
cargo build
```

## Running Tests

```bash
cargo test
```

## Code Style

- Run `cargo fmt` before committing
- Run `cargo clippy` and fix warnings
- Write documentation comments for public APIs
- Follow Rust naming conventions
- No `unwrap()` in production paths

## Pull Request Process

1. Fork the repository
2. Create a feature branch
3. Make your changes
4. Run tests and clippy
5. Submit a pull request

## Reporting Issues

Please use GitHub Issues to report bugs or request features.

## Philosophy

- Performance over convenience
- Transparency over magic
- Measurable over theoretical
- Maintainable over clever
